## ⚙️ Content Overview

The documentation directory contains comprehensive operational guides:

- **Setup & Environment Guide**: Virtual environment creation (`venv`), package installation via `pip`, and port configuration.
- **System Architecture Diagrams**: Object-Oriented software engineering diagrams detailing class relationships between `BaseGridGenerator`, `PrototypeGridGenerator`, `BaseExporter`, `PNGExporter`, and `MapGenApp`.
- **API Reference**: Detailed contract specifications for `/health`, `/api/generate`, and `/api/export`.
