### 1. Project Proposal & Objectives
- Maintains the official academic project proposal (`PBL_Project_Proposal.docx`).
- Defines project goals: developing deterministic procedural map generation algorithms (Cellular Automata, Perlin Noise, BSP trees) and serving them via a web-accessible REST API interface.

### 2. Academic Problem Statement
- Identifies game development challenges regarding manual level design effort and memory efficiency.
- Explores computational spatial partitioning solutions for fast, infinite procedural map generation.
