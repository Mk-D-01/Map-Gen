## 🎯 Primary Responsibilities

1. **Procedural Algorithm Architecture**: Design and implement generation algorithms extending `BaseGridGenerator`.
2. **Cellular Automata Engineering**: Implement 8-neighbor Moore Neighborhood evaluation routines for cave map smoothing.
3. **PRNG State Determinism**: Manage Python `random.seed(seed)` state initialization to guarantee reproducible grid matrices.
4. **Spatial & Noise Exploration**: Develop terrain algorithms including Perlin Noise heightmaps, BSP dungeon trees, and spatial hashing.
