## 🎯 Primary Responsibilities

1. **Client-Side DOM & UI Design**: Build clean, modern web interfaces using semantic HTML5 and glassmorphic CSS styling.
2. **HTML5 Canvas Rendering**: Calculate dynamic tile pixel dimensions and draw 2D procedural grid arrays.
3. **Asynchronous REST API Integration**: Use vanilla JS `fetch()` to send map parameter requests and handle API responses.
4. **Binary File Downloading**: Programmatically convert image BLOB data from `/api/export` into downloadable PNG files.

---

## 🛠 Key Tools & Technologies

- **Languages**: HTML5, CSS3 (Glassmorphism design system), Vanilla JavaScript (ES6+)
- **Graphics API**: HTML5 2D Canvas API
- **HTTP Client**: Native browser Fetch API & Blob API
