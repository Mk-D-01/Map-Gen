Memory Buffer Architecture

2D Spatial Grid & Flattened Matrix Buffer

Maps 2D spatial coordinate pairs $(x, y)$ onto a contiguous 1D array buffer, enabling $O(1)$ constant time tile access, high CPU L1/L2 cache locality, and zero memory overhead.

O(1) Direct Lookup
O(W × H) Contiguous
L1/L2 Friendly
Index = y * W + x

1. Data Structure Foundations

In game map generation, grids represent 2D tilemaps containing terrain types, wall flags, and elevation values. While a naive list of lists (e.g. grid[y][x]) is simple, it incurs multi-pointer dereferencing overhead and non-contiguous memory allocations.

The Flattened 2D Spatial Grid stores the entire 2D world inside a single contiguous 1D memory array in row-major order.

2. 1D Flattening Index Math

Converting back and forth between 2D coordinates $(x, y)$ and 1D buffer index $i$ is done with simple arithmetic:

2D to 1D Index Formula
Index(x, y) = y \cdot Width + x
1D to 2D Coordinate Inverse Formula
x = i \pmod{Width}, \quad y = \lfloor \frac{i}{Width} \rfloor

3. CPU Cache Locality & Performance

When processing grid algorithms (like Cellular Automata or Perlin sampling), adjacent cells along rows reside in consecutive memory addresses. This ensures prefetching into L1/L2 cache lines, boosting generation throughput.

4. Full Python Class Implementation

Here is a complete, object-oriented Python 3 implementation of the SpatialGrid2D data structure:

spatial_grid.py 
class SpatialGrid2D:
    def __init__(self, width: int, height: int, default_val=0):
        self.width = width
        self.height = height
        # Single contiguous 1D array buffer
        self.buffer = [default_val] * (width * height)

    def get(self, x: int, y: int):
        """O(1) spatial lookup with boundary check."""
        if 0 <= x < self.width and 0 <= y < self.height:
            return self.buffer[y * self.width + x]
        return None

    def set(self, x: int, y: int, val) -> bool:
        """O(1) spatial mutation."""
        if 0 <= x < self.width and 0 <= y < self.height:
            self.buffer[y * self.width + x] = val
            return True
        return False

    def get_neighbors_8(self, x: int, y: int):
        """Returns list of 8 Moore neighbor values."""
        neighbors = []
        for dy in (-1, 0, 1):
            for dx in (-1, 0, 1):
                if dx == 0 and dy == 0: continue
                val = self.get(x + dx, y + dy)
                if val is not None:
                    neighbors.append(val)
        return neighbors
