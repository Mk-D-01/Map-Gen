1. Algorithmic Overview

Cellular Automata (CA) grids model dynamic systems where cells evolve based on the states of their immediate neighbors. Made famous by Conway's Game of Life, CA algorithms are used in procedural level design to generate organic, subterranean cave maps.

The grid begins with a random noise pass (typically 45% wall density). Over successive smoothing passes (usually 4 to 6 iterations), noisy clusters coalesce into smooth cavern walls and open subterranean chambers.

2. The 4-5 Rule & State Hysteresis

A common bug in basic CA cave implementations is setting a cell to open floor if neighbor count is 4. This causes cave systems to collapse or erode into open voids.

The Corrected 4-5 Rule with State Hysteresis enforces memory of the cell's previous state when neighbor count equals 4:

State Transition Rule Formula
S_{t+1}(x, y) = \begin{cases} 1 \text{ (Wall)} & \text{if } \sum_{N_8} S_t > 4 \\ 0 \text{ (Floor)} & \text{if } \sum_{N_8} S_t < 4 \\ S_t(x, y) & \text{if } \sum_{N_8} S_t = 4 \end{cases}

3. Solid Boundary Padding

To prevent caves from bleeding out into map edges, the outermost grid border ($x=0, x=W-1, y=0, y=H-1$) is locked as indestructible solid walls (1). Additionally, any neighbor lookups outside map boundaries are counted as solid wall cells (1).

4. Flood-Fill Pocket Cleanup

Cellular Automata can occasionally leave tiny, isolated cave pockets disconnected from the main cave network. We run a Breadth-First Search (BFS) flood-fill pass to discover all connected cave components, keep the largest playable cavern, and fill small unplayable pockets back into solid rock.

5. Full Python Implementation

Here is the robust Python 3 implementation of our corrected 4-5 rule Cellular Automata cave solver:

cellular_cave_engine.py 
from collections import deque

def hash_coords(x: int, y: int, seed: int) -> float:
    n = (x + y * 57 + seed * 131) & 0xFFFFFFFF
    n = ((n << 13) ^ n) & 0xFFFFFFFF
    term = (n * (n * n * 15731 + 789221) + 1376312589) & 0x7FFFFFFF
    return 1.0 - (term / 1073741824.0)

def generate_cellular_cave(width: int, height: int, seed: int, fill_prob=0.45, passes=5):
    # Step 1: Initial Random Seed Pass with Solid Border
    grid = []
    for y in range(height):
        row = []
        for x in range(width):
            if x == 0 or x == width - 1 or y == 0 or y == height - 1:
                row.append(1) # Outer wall border
            else:
                h = (hash_coords(x, y, seed) + 1.0) * 0.5
                row.append(1 if h < fill_prob else 0)
        grid.append(row)

    # Step 2: Iterative 4-5 Rule Smoothing Passes
    for _ in range(passes):
        new_grid = [[1] * width for _ in range(height)]
        for y in range(1, height - 1):
            for x in range(1, width - 1):
                wall_count = 0
                for dy in (-1, 0, 1):
                    for dx in (-1, 0, 1):
                        if dx == 0 and dy == 0: continue
                        nx, ny = x + dx, y + dy
                        if nx < 0 or nx >= width or ny < 0 or ny >= height:
                            wall_count += 1
                        elif grid[ny][nx] == 1:
                            wall_count += 1

                # State hysteresis: >4 wall, <4 floor, ==4 retain existing state
                curr_val = grid[y][x]
                if wall_count > 4:
                    new_grid[y][x] = 1
                elif wall_count < 4:
                    new_grid[y][x] = 0
                else:
                    new_grid[y][x] = curr_val
        grid = new_grid

    # Step 3: Flood Fill Connectivity Pass (Keep largest cave body)
    visited = [[False] * width for _ in range(height)]
    caves = []

    for y in range(1, height - 1):
        for x in range(1, width - 1):
            if grid[y][x] == 0 and not visited[y][x]:
                current_cave = []
                q = deque([(x, y)])
                visited[y][x] = True
                while q:
                    cx, cy = q.popleft()
                    current_cave.append((cx, cy))
                    for dx, dy in ((1,0), (-1,0), (0,1), (0,-1)):
                        nx, ny = cx + dx, cy + dy
                        if 0 < nx < width - 1 and 0 < ny < height - 1:
                            if grid[ny][nx] == 0 and not visited[ny][nx]:
                                visited[ny][nx] = True
                                q.append((nx, ny))
                caves.append(current_cave)

    # Fill isolated small cavities back to walls
    if caves:
        largest_cave = max(caves, key=len)
        cave_set = set(largest_cave)
        for y in range(1, height - 1):
            for x in range(1, width - 1):
                if grid[y][x] == 0 and (x, y) not in cave_set:
                    grid[y][x] = 1

    return grid
