1. Neighborhood Types

Grid-based cellular algorithms sample surrounding cells to calculate local density:

  • Moore Neighborhood ($N_8$): Evaluates all 8 surrounding cells (orthogonal + diagonal). Used in Cellular Automata cave smoothing.
  • Von Neumann Neighborhood ($N_4$): Evaluates only the 4 orthogonal cells (North, South, East, West). Used in flood-fill connectivity and pathfinding.

2. Chebyshev vs. Manhattan Distance Math

Moore Neighborhood (Chebyshev Distance)
N_8(x, y) = \{ (x', y') \mid \max(|x - x'|, |y - y'|) = 1 \}
Von Neumann Neighborhood (Manhattan Distance)
N_4(x, y) = \{ (x', y') \mid |x - x'| + |y - y'| = 1 \}

3. Boundary Edge Handling

When evaluating cells along map edges ($x=0$ or $y=0$), out-of-bounds coordinates must be clamped or padded to prevent out-of-index crashes. In our engine, out-of-bounds cells return a solid wall state (1) to constrain caves inside map boundaries.

4. Full Python Module Implementation

Here is a Python 3 module implementing both neighborhood sampling kernels:

neighborhood_kernel.py 
def get_moore_neighbors(grid, x: int, y: int, width: int, height: int) -> int:
    """Counts 8 surrounding wall neighbors (Moore N8), treating out-of-bounds as wall."""
    count = 0
    for dy in (-1, 0, 1):
        for dx in (-1, 0, 1):
            if dx == 0 and dy == 0: continue
            nx, ny = x + dx, y + dy
            if nx < 0 or nx >= width or ny < 0 or ny >= height:
                count += 1
            elif grid[ny][nx] == 1:
                count += 1
    return count

def get_von_neumann_neighbors(grid, x: int, y: int, width: int, height: int) -> list:
    """Returns valid 4 orthogonal neighbor coordinates (Von Neumann N4)."""
    neighbors = []
    for dx, dy in ((1,0), (-1,0), (0,1), (0,-1)):
        nx, ny = x + dx, y + dy
        if 0 <= nx < width and 0 <= ny < height:
            neighbors.append((nx, ny))
    return neighbors
