Spatial Bitwise Hash Function

A 32-bit bitwise hash function that maps 2D coordinate pairs $(x, y)$ and integer random seeds into reproducible pseudo-random scalar values $[-1.0, 1.0]$ without lookup table overhead.

O(1) Bitwise Ops
0 Bytes (Stateless)
Strict Seed Math
[-1.0, 1.0] Normalized

1. Why Bitwise Hashing?

Standard pseudo-random number generators (like Python's random.random()) rely on sequential state mutations. In spatial level generation, we need to query random values at arbitrary grid coordinates $(x, y)$ out-of-order and reproducibly based on a seed.

A Spatial Bitwise Hash acts as a stateless pseudo-random function $f(x, y, seed) \to \mathbb{R}$.

2. Bitwise Formula & Bitshifts

Spatial Hash Bitwise Equation
n = (x + y \cdot 57 + seed \cdot 131) \ll 13 \oplus n \\ Hash = 1.0 - \frac{((n \cdot (n^2 \cdot 15731 + 789221) + 1376312589) \ \& \ 0x7FFFFFFF)}{1073741824.0}

3. Python 32-bit Integer Masking

In C/C++, integer overflow wraps around 32 bits automatically. Because Python handles arbitrarily large integers, we explicitly mask results with & 0xFFFFFFFF and & 0x7FFFFFFF to enforce identical 32-bit signed overflow behavior.

4. Full Python Function Implementation

Here is the full Python 3 spatial bitwise hash implementation:

spatial_hash.py 
def spatial_hash_2d(x: int, y: int, seed: int) -> float:
    """
    Stateless 32-bit Spatial Hash Function.
    Returns a deterministic pseudo-random float in [-1.0, 1.0].
    """
    # Mix coordinates with prime multipliers
    n = (x + y * 57 + seed * 131) & 0xFFFFFFFF
    
    # Bitwise XOR and shift
    n = ((n << 13) ^ n) & 0xFFFFFFFF
    
    # Quadratic congruence hashing with prime constants
    term = (n * (n * n * 15731 + 789221) + 1376312589) & 0x7FFFFFFF
    
    # Normalize to range [-1.0, 1.0]
    return 1.0 - (term / 1073741824.0)
