Binary Space Partitioning (BSP) Tree

A hierarchical binary tree data structure where each node represents a 2D bounding box $(x, y, w, h)$ split recursively into two child nodes until leaf nodes hold carved room geometries.

1. Tree Architecture

A BSP Tree is a recursive data structure used to subdivide a 2D bounding space into smaller convex regions.

The root node represents the entire map bounds. Non-leaf interior nodes store splitting axes (horizontal or vertical) and pointers to left and right subtrees. Leaf nodes store the final carved room coordinates.

2. Node Definition & Memory Layout

BSP Node Structure Definition
Node = \{ x, y, width, height, left: Node*, right: Node*, room: Rect \}

3. Recursive Tree Traversal

To carve rooms and establish corridor paths, we perform a Depth-First Search (DFS) or Breadth-First Search (BFS) traversal down to leaf nodes:

  • Leaf Collection: If left and right are None, the node is a leaf holding room data.
  • Corridor Routing: Connecting room centroids of sibling leaves creates connected room graphs without cycles.

4. Full Python Class Implementation

Here is a complete Python 3 implementation of the BSPNode and BSPTree classes:

bsp_tree.py 
class BSPNode:
    def __init__(self, x: int, y: int, width: int, height: int):
        self.x = x
        self.y = y
        self.width = width
        self.height = height
        self.left = None
        self.right = None
        self.room = None

    def is_leaf(self) -> bool:
        return self.left is None and self.right is None

    def get_leaves(self):
        """Recursively gathers all leaf nodes in tree."""
        if self.is_leaf():
            return [self]
        leaves = []
        if self.left: leaves.extend(self.left.get_leaves())
        if self.right: leaves.extend(self.right.get_leaves())
        return leaves
