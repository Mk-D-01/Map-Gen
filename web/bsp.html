Binary Space Partitioning (BSP)

Recursively bisects rectangular map bounds into a hierarchical binary tree, carving room chambers inside leaf node boundaries and linking sibling centroids using L-shaped corridor graphs.

1. Algorithmic Overview

Binary Space Partitioning (BSP) is a classic spatial subdivision algorithm widely used in game engines (such as Doom and Quake) for level geometry, collision detection, and dungeon floorplan synthesis.

Starting with a root rectangle covering the full map area, BSP recursively splits sub-regions either horizontally or vertically into binary child nodes until a minimum room size constraint is met.

2. Spatial Tree Bisection

The bisection decision evaluates node aspect ratios to maintain balanced room proportions:

Split Axis Selection Rule
SplitDirection = \begin{cases} \text{Horizontal} & \text{if } \frac{H}{W} \ge 1.25 \\ \text{Vertical} & \text{if } \frac{W}{H} \ge 1.25 \\ \text{Random Seed Choice} & \text{otherwise} \end{cases}

3. Room Carving Logic

Once node splitting completes, rooms are carved inside each leaf node boundary ($Rw \approx 70\% \cdot W, Rh \approx 70\% \cdot H$). Carving rooms smaller than leaf node bounds guarantees that rooms never overlap and always leave wall space for corridors.

4. Corridor Routing Graphs

To ensure all carved rooms are fully reachable, the algorithm connects room centroids $(Cx, Cy)$ between adjacent sibling leaves using L-shaped horizontal and vertical corridor line segments.

5. Full Python Implementation

Here is the full Python 3 implementation of the BSP Dungeon Generator:

bsp_dungeon_engine.py 
import math

def hash_coords(x: int, y: int, seed: int) -> float:
    n = (x + y * 57 + seed * 131) & 0xFFFFFFFF
    n = ((n << 13) ^ n) & 0xFFFFFFFF
    term = (n * (n * n * 15731 + 789221) + 1376312589) & 0x7FFFFFFF
    return 1.0 - (term / 1073741824.0)

class BSPNode:
    def __init__(self, x: int, y: int, w: int, h: int):
        self.x, self.y, self.w, self.h = x, y, w, h
        self.left = None
        self.right = None
        self.room = None

    def split(self, min_size: int, seed: int) -> bool:
        if self.left or self.right: return False

        split_h = False
        if self.w / self.h >= 1.25: split_h = False
        elif self.h / self.w >= 1.25: split_h = True
        else: split_h = hash_coords(self.x, self.y, seed) > 0

        max_size = (self.h if split_h else self.w) - min_size
        if max_size <= min_size: return False

        split_pos = min_size + int((max_size - min_size) * 0.5)

        if split_h:
            self.left = BSPNode(self.x, self.y, self.w, split_pos)
            self.right = BSPNode(self.x, self.y + split_pos, self.w, self.h - split_pos)
        else:
            self.left = BSPNode(self.x, self.y, split_pos, self.h)
            self.right = BSPNode(self.x + split_pos, self.y, self.w - split_pos, self.h)
        return True

    def create_rooms(self, grid, width: int, height: int):
        if self.left or self.right:
            if self.left: self.left.create_rooms(grid, width, height)
            if self.right: self.right.create_rooms(grid, width, height)
        else:
            rw = max(3, int(self.w * 0.7))
            rh = max(3, int(self.h * 0.7))
            rx = self.x + (self.w - rw) // 2
            ry = self.y + (self.h - rh) // 2
            self.room = {'x': rx, 'y': ry, 'w': rw, 'h': rh, 'cx': rx + rw // 2, 'cy': ry + rh // 2}

            for py in range(ry, ry + rh):
                for px in range(rx, rx + rw):
                    if 0 < py < height - 1 and 0 < px < width - 1:
                        grid[py][px] = 1 # 1 = Room floor

    def get_rooms(self):
        if self.room: return [self.room]
        rooms = []
        if self.left: rooms.extend(self.left.get_rooms())
        if self.right: rooms.extend(self.right.get_rooms())
        return rooms

def generate_bsp_dungeon(width: int, height: int, seed: int, min_room_size=6):
    grid = [[0] * width for _ in range(height)]
    root = BSPNode(1, 1, width - 2, height - 2)
    nodes = [root]

    for i in range(5):
        for j in range(len(nodes)):
            n = nodes[j]
            if n.split(min_room_size, seed + i * 10 + j):
                nodes.append(n.left)
                nodes.append(n.right)

    root.create_rooms(grid, width, height)
    rooms = root.get_rooms()

    for i in range(len(rooms) - 1):
        r1, r2 = rooms[i], rooms[i + 1]
        cx, cy = r1['cx'], r1['cy']
        while cx != r2['cx']:
            grid[cy][cx] = 2 # 2 = Corridor
            cx += 1 if r2['cx'] > cx else -1
        while cy != r2['cy']:
            grid[cy][cx] = 2
            cy += 1 if r2['cy'] > cy else -1

    return grid
