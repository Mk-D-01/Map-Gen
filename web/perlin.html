Perlin & Smooth Value Noise

Continuous, gradient-based pseudo-random noise used to generate natural terrain heightmaps, biomes, continental drift lines, and organic textures without grid artifacts.

1. Algorithmic Basics

Pure random noise (white noise) assigns independent values to every coordinate. In game level generation, this produces chaotic static noise rather than natural landscapes.

Perlin & Smooth Value Noise solves this by constructing a continuous multi-dimensional gradient field. Adjacent grid coordinates produce smooth, gradual height transitions (mountains smoothly scaling down to coasts and ocean trenches).

2. Mathematical Formulation

The noise generation pipeline executes four distinct mathematical steps:

Step A: Spatial Hash Interpolation

Converts integer lattice coordinates (X, Y) into a deterministic random float using bitwise ops:

Hash(X, Y, Seed) = 1.0 - \frac{((n \cdot (n^2 \cdot 15731 + 789221) + 1376312589) \ \& \ 0x7FFFFFFF)}{1073741824.0}
Step B: Quintic Hermite Fade Curve

To eliminate linear slope discontinuities, fractional offsets (xf, yf) pass through a 5th-degree polynomial:

Fade(t) = 6t^5 - 15t^4 + 10t^3
Step C: Bilinear Interpolation (Lerp)

Blends four lattice corners $N_{00}, N_{10}, N_{01}, N_{11}$ using smoothed weights $u = Fade(xf)$ and $v = Fade(yf)$:

Lerp(a, b, t) = a + t \cdot (b - a)

3. Multi-Octave Superposition (Fractal Noise)

Single-pass noise looks smooth but lacks fine terrain details (like small hills or sharp ridge edges). We layer multiple noise passes ("octaves") at increasing frequencies and decreasing amplitudes:

Fractal Noise Equation
Noise_{total}(x, y) = \sum_{o=0}^{O-1} \text{Amplitude}^o \cdot SmoothNoise(x \cdot 2^o, y \cdot 2^o)

4. Full Python Implementation

Below is the complete, standalone Python 3 implementation of our multi-octave smooth value noise engine:

perlin_engine.py 
import math

def hash_coords(x: int, y: int, seed: int) -> float:
    """Bitwise 32-bit spatial hash producing deterministic float in [-1.0, 1.0]."""
    n = (x + y * 57 + seed * 131) & 0xFFFFFFFF
    n = ((n << 13) ^ n) & 0xFFFFFFFF
    term = (n * (n * n * 15731 + 789221) + 1376312589) & 0x7FFFFFFF
    return 1.0 - (term / 1073741824.0)

def smooth_fade(t: float) -> float:
    """Quintic Hermite polynomial: C2 continuous smoothing."""
    return t * t * t * (t * (t * 6.0 - 15.0) + 10.0)

def smooth_noise_2d(x: float, y: float, seed: int) -> float:
    """Evaluates 2D continuous noise at fractional coordinate (x,y)."""
    X, Y = math.floor(x), math.floor(y)
    xf, yf = x - X, y - Y

    u = smooth_fade(xf)
    v = smooth_fade(yf)

    n00 = (hash_coords(X, Y, seed) + 1.0) * 0.5
    n10 = (hash_coords(X + 1, Y, seed) + 1.0) * 0.5
    n01 = (hash_coords(X, Y + 1, seed) + 1.0) * 0.5
    n11 = (hash_coords(X + 1, Y + 1, seed) + 1.0) * 0.5

    x1 = n00 + u * (n10 - n00)
    x2 = n01 + u * (n11 - n01)
    return x1 + v * (x2 - x1)

def generate_perlin_map(width: int, height: int, seed: int, scale=0.04, octaves=3, persistence=0.3):
    """Generates a 2D matrix of terrain height values in range [0.0, 1.0]."""
    grid = []
    for y in range(height):
        row = []
        for x in range(width):
            total_noise = 0.0
            freq = scale
            amp = 1.0
            max_amp = 0.0

            for o in range(octaves):
                total_noise += smooth_noise_2d(x * freq, y * freq, seed + o * 100) * amp
                max_amp += amp
                freq *= 2.0
                amp *= persistence

            row.append(total_noise / max_amp)
        grid.append(row)
    return grid

5. Biome Palette Mapping

The output scalar map (values from 0.0 to 1.0) is thresholded into distinct terrain biomes:

  • Deep Water: Height < 0.42 (Navy color #4b5587)
  • Sandy Coast: 0.42 ≤ Height < 0.48 (Sand color #d2be8c)
  • Meadow: 0.48 ≤ Height < 0.62 (Grass color #91b96e)
  • Dense Forest: Height ≥ 0.62 (Forest color #508755)
