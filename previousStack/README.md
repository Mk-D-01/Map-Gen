# 🏛️ Previous Stack Module — Legacy C Prototypes

Welcome to the **Previous Stack** directory! This folder contains early C-language prototypes, compiled executable binaries, and initial map output benchmarks from the first iteration of the project.

## ⚙️ Content & Historical Context

Before migrating to Python and HTML5 Canvas, the procedural generation logic was prototyped in raw C for maximum execution speed:

- **Algorithm Proof-of-Concept**: `map_gen_1.c` and `map_gen_image.c` implemented baseline random fill array operations and matrix image buffer creation.
- **Compiled Binaries**: `map_gen.exe` and `a.exe` demonstrate low-level memory management and direct file IO generation of sample outputs (`map_output.png`).
