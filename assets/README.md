# 🖼️ Assets Module — Visual Resources & Tile Packs

Welcome to the **Assets** directory! This folder holds visual graphics, sprite sets, tile maps, and screenshot captures used by the frontend applications and visualizers.

---

## 🧒 Explain Like I'm 5 (ELI5)

> Imagine a **Box of Crayons & Stickers**:
>
> 1. When the map generator builds a cave or dungeon, it needs pretty pictures to draw grass, rocks, water, and wall textures.
> 2. This folder is the **Sticker Box** where all these graphical tiles and preview pictures live!

---

## ⚙️ Content & Structure

The assets directory is categorized into numerical pack folders:

- **Tile Sets & Graphics**: Image textures for terrain rendering (floors, walls, terrain height layers).
- **Visual Captures**: Screenshots and sample output renders used across documentation and visualizer pages.

---

## 📂 Subdirectories

| Folder | Description |
| :--- | :--- |
| 📂 `1/` | Primary tile set & map preview assets (Pack 1). |
| 📂 `2/` | Secondary visual assets & terrain textures (Pack 2). |
| 📂 `3/` | Additional UI & canvas preview assets (Pack 3). |
| 📂 `5/` | Sample output renders and exported map benchmarks (Pack 5). |
